---
name: reading-practice
description: Create an exam-style reading or Use of English task with an original text, questions and a hidden key, then mark the answers. Use when the user asks for reading practice, a reading test, Use of English, key word transformations, or gap-fills.
---

1. Read the target exam and level from `CLAUDE.md`. Pick a task type from that exam's Reading (or Reading and Use of English) paper, e.g. C1 Advanced Part 5 multiple choice, B2 First Part 4 key word transformations, IELTS Academic matching headings. Use only task types the exam really has; if unsure of the format, say so and link to the official sample papers instead of guessing. Rotate task types across sessions (check earlier files in `reading/`).
2. Write an original text at the target level (never copy a published one) and the questions in the exact exam format to `reading/YYYY-MM-DD-<topic>.md`: task instructions, text, questions, then the answer key under a `## Key` heading at the end. For Use of English, base items on the learner's top grammar, collocation and vocabulary categories in `log/errors.csv` where they fit the task (research/prompts.md T5 and T10 show the style). Do not show the text or key in the chat; tell the learner to open the file, set a timer using the exam's real time per task if known, and not scroll to the key.
3. When the learner sends answers, mark them. Reading: quote the line that proves each answer and say why the chosen distractor is wrong. Key word transformations: mark 0/1/2 as Cambridge does and explain lost marks. Prompt self-correction once on each wrong Use of English item before giving the answer.
4. Log each wrong answer to `log/errors.csv`: comprehension mistakes as category `reading` (original = their answer, correction = the right answer, explanation = what they missed); wrong Use of English items under the matching language category (grammar, collocation, etc.). `source` = the task file name.
5. Append one row to `log/study.csv` (`date,minutes,strand,activity`, e.g. `2026-10-07,35,exam,reading C1 Part 5`) with strand `exam` if timed under exam conditions, otherwise `input`. Ask the learner how long it took if they did not say.
