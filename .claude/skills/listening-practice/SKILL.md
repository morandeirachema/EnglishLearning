---
name: listening-practice
description: Create an exam-style listening task with real audio generated by macOS voices, plus questions and a hidden key. Use when the user asks for listening practice, a listening test, or audio to practise with.
---

1. Read the target exam and level from `CLAUDE.md`. Pick the matching task type (e.g. B2 First Listening Part 4 interview, C1 Part 3, IELTS Section 3 discussion).
2. Write the script to `listening/YYYY-MM-DD-<topic>.txt`. Format: one turn per line as `A: ...`, `B: ...` (up to D); an unprefixed line is the narrator. Lines starting with `#` are comments. Use natural spoken features: hesitation, reformulation, distractors that are mentioned then rejected.
3. Generate audio: `python3 scripts/listening.py <file> --twice` (add `--rate 150` below B2). Speakers A/B are British, C is Irish, D is Australian, to match exam accent variety.
4. Write questions in the exact exam task type to `listening/YYYY-MM-DD-<topic>-questions.md`. Put the answer key under a `## Key` heading at the end, and tell the learner not to scroll to it. Do not show the script or key in the chat.
5. Tell the learner to play the `.m4a` (on the Mac, or copy to the Pixel via Google Drive) and send their answers. Mark them, quoting the script line that proves each answer, and log errors with `/log-errors` categories in `log/errors.csv` (category `listening`).
